# 🎯 English Pro SaaS

Master English grammar structures and improve your English conversation skills with interactive learning!

## Features

✨ **25 English Structures** - Learn the most used structures in English
📚 **8 Examples Per Structure** - Practice with real-world examples
🔊 **Text-to-Speech** - Hear native pronunciation
🎤 **Speech Recognition** - Practice speaking and get feedback
💬 **AI Chatbot** - Get instant corrections on your English
🌐 **Bilingual Interface** - English & French support
📱 **Mobile Optimized** - Perfect for learning on your iPhone
